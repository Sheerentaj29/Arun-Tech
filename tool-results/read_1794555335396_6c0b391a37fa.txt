    96→    96→// PIPE STANDARD REFERENCE DATA (ASME B36.10M / B36.19M)
    97→    97→// =====================================================
    98→    98→// Wall thickness values seeded from the publicly published ASME
    99→    99→// reference tables for the most commonly used nominal pipe sizes and
   100→   100→// schedules. These values MUST be re-verified against the licensed /
   101→   101→// official ASME standard edition by an authorized administrator before
   102→   102→// production use. An admin can edit, add, or delete entries, and every
   103→   103→// edit is recorded with verifiedBy + verifiedAt + audit log entry.
   104→   104→
   105→   105→model PipeStandard {
   106→   106→  id              String   @id @default(cuid())
   107→   107→  standard        String   // "ASME B36.10M" | "ASME B36.19M"
   108→   108→  edition         String   // e.g. "2018"
   109→   109→  nominalSizeInch String   // e.g. "2" or "1/2"
   110→   110→  nominalSizeMm   Float   // e.g. 60.3
   111→   111→  dn              String   // e.g. "DN50"
   112→   112→  schedule        String   // e.g. "SCH 40", "STD", "XS", "XXS", "SCH 40S"
   113→   113→  wallThicknessMm Float   // nominal wall thickness in mm
   114→   114→  oD_mm           Float?   // outside diameter (mm) when applicable
   115→   115→  isVerified      Boolean  @default(false)
   116→   116→  verifiedById    String?
   117→   117→  verifiedAt      DateTime?
   118→   118→  notes           String?
   119→   119→  createdAt       DateTime @default(now())
   120→   120→  updatedAt       DateTime @updatedAt
   121→   121→
   122→   122→  verifiedBy      User?    @relation("PipeStandardVerifiedBy", fields: [verifiedById], references: [id], onDelete: SetNull)
   123→   123→  measurements    ThicknessMeasurement[]
   124→   124→
   125→   125→  @@unique([standard, edition, nominalSizeInch, schedule])
   126→   126→  @@index([standard, nominalSizeInch])
   127→   127→}

   392→   392→// =====================================================
   393→   393→// THICKNESS MEASUREMENT ROW
   394→   394→// =====================================================
   395→   395→// One row per measurement point. The first two columns (Dia mm (inch),
   396→   396→// Pipe Schedule) are stored as structured values; the third column
   397→   397→// (Nominal Thickness) is calculated from PipeStandard and may be
   398→   398→// overridden only with a recorded reason. The four clock-position
   399→   399→// measurements support an explicit status (Measured | NotMeasured |
   400→   400→// NotApplicable) so missing data is never converted to zero.
   401→   401→
   402→   402→model ThicknessMeasurement {
   403→   403→  id                    String   @id @default(cuid())
   404→   404→  pipelineInspectionId String
   405→   405→  pointNo               String   // free text, e.g. "P-1"
   406→   406→  sortOrder             Int      @default(0)
   407→   407→
   408→   408→  // ─── Multi-table grouping (additive, default "default") ───
